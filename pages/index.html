Gerekli ilk kurulum

  1. GitHub Actions secrets içine RCLONE_CONFIG_B64 ve RCLONE_DESTINATION ekle.
  2. Render'da DISCORD_BOT_TOKEN, GITHUB_TOKEN, UBAGEN_ADMIN_TOKEN ve UBAGEN_DISCORD_ADMIN_IDS ayarla.
  3. GitHub deposu Settings → Pages → Build and deployment → Source alanında GitHub Actions seç.
  4. GitHub Actions variables alanına RENDER_HEALTH_URL olarak Render adresinin /health yolunu ekle.
Ücretsiz Render uykuya geçebilir veya yeniden başlayabilir. Zamanlanmış ping en iyi çabadır; 7/24 çalışma garantisi vermez. GitHub Actions'ın ücretsiz kotası ve iş süresi sınırları da geçerlidir.
